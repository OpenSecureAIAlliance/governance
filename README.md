## How to Propose a New Working Group

1. Read [`process/wg-formation.md`](./process/wg-formation.md)
2. Copy [`process/templates/WG_NAME_proposal.md`](./process/templates/WG_NAME_proposal.md) and fill it in
3. Open a pull request adding your completed proposal to [`process/wg-proposals/`](./process/wg-proposals/)
4. The Steering Committee will review and vote
